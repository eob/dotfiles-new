# Agent Model

This directory houses the structured epistemic memory of the agent:

- [`claims.md`](claims.md) — Atomic claims ledger tracking verified knowledge.
- [`uncertainties.md`](uncertainties.md) — Hypotheses and active questions being tested.
- [`evidence-policy.md`](evidence-policy.md) — Rules for evidence classification.
- [`revisions.md`](revisions.md) — Historical changelog of claims.
